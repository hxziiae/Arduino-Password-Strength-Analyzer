# Arduino-Password-Strength-Analyzer
A personal Arduino project that evaluates password strength and displays the result using an LCD screen and LED indicators.

## Features
- Classifies passwords as weak, medium, or strong
- Uses red, yellow, and green LEDs
- Displays the result on a 16x2 LCD
- Identifies missing password requirements through the Serial Monitor
- Checks length, uppercase letters, lowercase letters, digits, and symbols

## Hardware
- Arduino Uno
- 16x2 LCD with I2C module
- Breadboard
- Red, yellow, and green LEDs
- Resistors
- Jumper wires
